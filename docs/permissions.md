# ULTRA permissions

- `storage`: store local preferences and enabled mini-tools.
- `activeTab`: temporary access to the active tab after a user gesture.
- `scripting`: launch page tools only when requested by the user.
- `contextMenus`: provide a shortcut to open ULTRA.
- `sidePanel`: Chromium workspace surface where supported.

No broad website access is requested at install time. Page content stays on-device; there is no telemetry or remote code.
